# Reduce the inherited boilerplate

This deliverable plan owns [Foundation 3: Reduce the inherited boilerplate](../../ROADMAP.md#3-reduce-the-inherited-boilerplate). Imported scaffolding must remain minimal and maintainable without taking ownership of ordinary app builds. The first active requirement is [restoring the framework submodule](framework-submodule.md): the copied tree prevents normal upstream version control. Other cleanup and resource-baseline requirements remain unstarted.

Preserve host behavior, local work and the canonical build entrypoint. This checkpoint restores dependency ownership; it does not migrate the host into newer optional pipeline policies.
