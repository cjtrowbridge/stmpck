# Settings overrides

For [Implement settings overrides](../../ROADMAP.md#9-implement-settings-overrides), coordinate working app-wide menu-animation, master-audio, haptics, and decorative-effect controls. These must override intensity without changing game rules, with accessible controls and consistent lifecycle behavior.

## Status and boundaries

Unstarted; only the settings mockup is currently being implemented. Create one plan per requirement when detailed planning starts. Do not present mock switches as working controls. Implement session behavior first; saving these overrides remains part of the separate post-five-games [preferences plan](menu-preferences.md). Default sound remains off, and intensity determines menu autoplay unless a working animation override is enabled.


The gear screen also previews a Games wide selector (1–8, default 3). A later roadmap requirement will implement and persist that preference and reflow navigation/hit targets. The current gallery is fixed at three columns.
