# 2026-11-12 — Canonical open-source build toolchain

The user directed that the repo canonically require and use an open-source alternative to the JDK. Decision: Debian's open-source `openjdk-21-jdk-headless` package is the canonical Java toolchain (OpenJDK 21 is the last major whose `javac` accepts `-source 8 -target 8`, which APK packaging relies on; a different major is fatal, not a warning), and Debian's `adb` package is the canonical ADB. This replaces the previous unowned manual step ("provide a JDK on PATH or at `.tools/jdk/` and install Platform-Tools separately").

`scripts/setup_android.py` now installs the pinned SDK/NDK archives as before and then verifies `java`/`javac`/`jar`/`keytool` at major 21 and `adb` on `PATH`, printing the exact `sudo apt-get install -y openjdk-21-jdk-headless adb` remedy and exiting non-zero until satisfied; it never runs `sudo` itself. `scripts/build_android.py` prerequisite messages now name the canonical package. README and AGENTS are updated to match. Mapped roadmap item and plan: `plans/current/open-source-build-toolchain.md`.

Documentation and tooling only; no app behavior changed. Package installation is the operator's action (elevated privileges are never routed through the assistant). Local review and script syntax checks only — a canonical `build.py --verify --launch-android` run after the operator installs the packages remains open evidence.
