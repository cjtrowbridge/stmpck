# 2026-11-07 — STMPCK playable prototype checkpoint

This checkpoint records the accumulated transition from the imported Ebitengine boilerplate to the private, offline STMPCK game collection. The product direction is canonical in README/AGENTS and the detailed scope in ROADMAP. Earlier journal entries describe historical boilerplate work, not the current application state.

## Implemented

- Five offline games: Merge, Snake, Territory, Linear, and Bounce, with shared live previews, local session saves, pause/new/back navigation, and corruption recovery.
- Three-column gallery mosaic with matching hit targets, focus, and scroll geometry. Games wide (1–8, default 3) is visible in the gear mockup only. Working layout selection and persistence remain future work.
- Personal play counts; bundled global placeholder scores (Snake 100, Merge 90, Bounce 80, Linear 70, Territory 60); discovery filters to never-played games in global order. These are explicitly synthetic familiarity estimates, not market-share statistics or online telemetry. Sources and rationale are in the tab plan.
- Eight bounded intensity levels, silent animated launch default, same-row edge intensity controls, still levels left of default, breathing/rainbow/sparkle effects, and click-only in-game intensity changes.
- Merge: stacked 4/5/6 grid choices start immediately, fixed 2048 goal, distinct exponent colors, exact undo, and 200 ms sliding tiles with queued input; animated previews use tile travel too.
- Snake: screen swipes with keyboard/controller alternatives and no touch arrow pad. Bounce: relative vertical gestures anywhere on screen.
- Territory: seeded organic maps and previews; independent map/start shuffles; 1–3 opponents; one territory and ten units per player with neutral remainder. All sides run concurrently, produce one unit per owned territory every three seconds, and issue irreversible adjacent moves at 0.12 map units/sec. Dispatch subtracts all but one unit immediately. Arrivals reinforce or resolve dice combat. Old maps/armies migrate in place; flight progress and clocks persist without offline catch-up. High-contrast dots, complete bitmap counts, and friendly/hostile/neutral border palettes improve readability.
- Linear: computer-only play; old two-player boards migrate without resets. Future PvP is explicitly deferred.
- Android build/ADB setup and canonical VS Code launch build, install, and launch the current debug APK on the authorized test phone. Android Back and foreground keep-screen-on behavior are integrated. No store release was configured.
